## Niri Fundamentals

[Niri] is different from Plasma or GNOME. Imagine it as an endless grid of rows and columns, where instead of windows overlapping each other, they tile side by side. You can slide windows along rows, or move them up and down into the columns of adjacent workspaces. 

Almost everything in Niri is done using keyboard shortcuts or trackpad gestures, most use the <kbd>Super</kbd> key (aka Windows or ⌘ key).

### Noctalia Shell

[Noctalia] is a desktop shell that sits on top of Niri. It provides the bar, launcher, theming, control center, settings, a login page, and much more.

## Configuration


### Niri

Your personal changes to the Niri config go in `~/.config/niri/config.kdl`. This file starts with two `include` lines, one loads Ultramarine's defaults from `/etc/niri/config.kdl`, and the other loads the colors Noctalia generates for your theme. Anything you add below them is applied on top, so you only need to write the settings you want to change.

For example, to make <kbd>Super</kbd> + <kbd>T</kbd> open Kitty instead of Alacritty, add this to the end of the file:

```kdl
binds {
    Mod+T { spawn "kitty"; }
}
```

`Mod` is the <kbd>Super</kbd> key. Niri applies your changes as soon as you save the file, and shows an error notification if something is wrong. Avoid editing `/etc/niri/config.kdl` directly, keeping your changes in their own file means you still get Ultramarine's improved defaults when updating. See the [Niri documentation][niri-config] for more.

### Noctalia

Most of Noctalia can be configured through its settings app. Changes are saved to `~/.local/state/noctalia/settings.toml` and override `~/.config/noctalia/`. See the [Noctalia docs][noctalia-docs] for more.

<Alert type="info">
    You can also sync theme changes with the login screen by going to **Security → Noctalia Greeter → Sync Now** in Noctalia settings.
</Alert>

#### Theming Apps

Noctalia uses templates to recolor many apps to match your theme. You can toggle templates on and off, or browse many community templates for more apps, in **Settings → Templates**. See [Noctalia's app theming docs][noctalia-templates] for more.

If an app hasn't picked up your colors, for example Thunderbird after you first set it up, apply the templates again:

```sh
noctalia msg templates-apply
```

<Alert type="info">
    To theme Firefox, install the [Pywalfox extension][pywalfox] and restart Firefox once. We've already enabled the Firefox template, but decided not to install its accompanying extension by default.
</Alert>

## Troubleshooting

### Black Screen in a Virtual Machine

Niri needs a GPU with 3D acceleration and will not start with software rendering. In a virtual machine (GNOME Boxes, virt-manager, VirtualBox, etc.), enable **3D acceleration** in the VM's display settings. Without it, the screen stays black or stops at a text message about `import-environment`. See [Niri's notes on virtual machines][Niri-vm].
